Recorded against this entry in csf.deny - required, so csf never has to guess one from a reverse DNS lookup.

Block (temporary)

Leave blank to block all ports. At most 20 ports/ranges, TCP only when ports are given.

Allow

Allowing exempts an address from the firewall entirely. This is a security decision, not a support action.

Unblock

Removes a permanent block. To remove a temporary block or an allow entry, use the Lists screen instead.
